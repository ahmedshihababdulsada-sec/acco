# تجربة وصل A5 بالعربي (Flutter)

تجربة المرحلة 0 من خطة مركز التجميل: هل Flutter يطلع وصل A5 عربي صحيح، ويطبعه على طابعة Windows؟

## شنو انجرب فعلياً (على Mac، 2026-11-13)
- توليد PDF بمقاس **A5 بالضبط (148×210 مم)** بـ `pdf` + خط **IBM Plex Sans Arabic** (OFL).
- الحروف العربية متصلة وبترتيب صحيح، رقم الوصل `2026-00131` ورمز الزبون `C-0977` والنسب `20%` تطلع بترتيبها، وصفحتين للوصل الطويل، وأسوأ حالة (أسماء طويلة، مبالغ 99,000,000).
- `flutter test`: 3 اختبارات تمر (حساب التقريب لـ250، صفحة وحدة للقصير، صفحتين للطويل). `flutter analyze`: بدون أخطاء.

## انجرب على الورق (2026-11-13)
- وصل قصير A5 انطبع من الماك على Canon MF664Cdw (Wi-Fi، tray-1، وجه واحد، بدون تصغير) والمقاس والهوامش والخط مضبوطين حسب صاحب المشروع. الأمر: `lp -d Canon_MF660C_Series -o media=A5 -o InputSlot=tray-1 -o sides=one-sided -o fit-to-page=false -o print-scaling=none receipt_short.pdf`

## شنو ما انجرب (لازم على حاسبة العيادة Windows)
- الطباعة المباشرة بدون نافذة من التطبيق، وسلوك سواقة Windows مع A5، وطباعة الوصل الطويل.
- تشغيل التطبيق نفسه على Windows (هنا ما أكو Xcode ولا Windows).

## تشغيله على Windows
```
flutter doctor            # لازم Visual Studio مع Desktop development with C++
flutter pub get
flutter run -d windows
```
بالواجهة: اختر الوصل (قصير / طويل / أسوأ حالة)، اختر الطابعة، واضغط **طباعة مباشرة**. أو **نافذة الطباعة**.

## قائمة فحص الطباعة (ورقة A5 حقيقية)
1. المقاس: الوصل ما ينصغّر (قيس العرض بالمسطرة: 148 مم ورق، والكتابة تبدأ بعد حوالي 10.6 مم من الحافة).
2. الحروف العربية متصلة والأرقام صحيحة، و`2026-00131` بنفس الترتيب.
3. الحدود السوداء ما تنقطع، وعمود المبالغ على حافة وحدة.
4. الوصل الطويل: صفحتين، المجاميع مع آخر بندين بالصفحة الثانية.
5. بدء الطباعة بدون فتح نافذة (Direct print) يشتغل على طابعتكم.
6. إذا الطابعة عطلت: الوصل ما ينحفظ بالطابعة، ويعاد طبعه (تجربة قطع الطابعة).

## اكتشافات مهمة للنظام الحقيقي
1. **خط Noto Naskh Arabic ما يصلح للوصل**: ما بيه `- / · [ ] % + −` ولا الحروف اللاتينية (تطلع مربعات). استعملنا IBM Plex Sans Arabic (نفس خط النماذج) وبيه كل شي.
2. **المسافة بين الكلمات العربية تطلع صفر** بمكتبة `pdf` مع هذا الخط إلا إذا انضبط `wordSpacing` (حوالي 16% من حجم الخط).
3. **النص العربي المختلط بـ`%` أو حروف لاتينية** ينقلب أو تضيع مسافاته؛ ولا نستعمل رموز العزل (U+2066 وغيرها) لأن المكتبة تطلعها مربعات. الحل: **تقسيم النص لمقاطع** (عربي / LTR) وصف RTL من المقاطع، ومعها **تقطيع الأسطر يدوياً بقياس عرض الكلمات** لأن `pw.Wrap` يرتب LTR. الكود بـ `lib/receipt/mixed_text.dart`.
4. **`Container` و`Column` و`SizedBox` كلها تنشطر بين الصفحات** بمكتبة `pdf`، فتنفرد المجاميع بصفحة لحالها. الحل: **`pw.Inseparable`** حول (آخر بندين + المجاميع + الدفع).
5. **«د.ع» جنب المبلغ الكبير** تطلع برا الهامش الأيسر؛ نقلناها لعنوان الصف («الصافي (د.ع)»).
6. الرأس والتذييل يتكررون بكل صفحة (الرأس أطول إذا الاسم والعنوان طوال)، وعنوان جدول البنود **ما يتكرر** بالصفحة الثانية (غير مطلوب بالتصميم الحالي).
